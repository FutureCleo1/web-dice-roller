# Web Dice Roller

## Author

Chloe Washington

## Project Description

The Web Dice Roller is a simple web application that simulates
rolling five six-sided dice for a game such as Yahtzee.

The application automatically rolls the dice when the page loads.
Users can click the Roll Dice button or press Enter to roll the
dice again.

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub
- Microsoft Azure

## How to Use

1. Open the website.
2. The five dice automatically roll when the page loads.
3. Click the Roll Dice button to roll again.
4. Press Enter to roll the dice again when the Roll button is focused.
5. Each die generates a random number between 1 and 6.

## Random Number Generation

JavaScript's Math.random() function is used to generate random
numbers between 1 and 6.
